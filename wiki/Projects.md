# 🚀 Featured Projects

## Flagship Engineering Projects

### 🇮🇳 OIML NAWI Metrology Tester (R-76)
**Automated OIML R-76 Guided NAWI Testing Suite**

- **Description:** A guided testing suite and verification system designed for Smart India Hackathon 2026 (SIH26035). Implements automated compliance testing for non-automatic weighing instruments (NAWI).
- **Core Technologies:** Python, Ed25519 Cryptographic Verification, ISO 19005-3 PDF/A-3, PTB DCC v3.2.1 XML, Docker
- **Repository:** [OIML-NAWI-METROLOGY-TESTER-R-76](https://github.com/Manshi-Chauhan/OIML-NAWI-METROLOGY-TESTER-R-76)
- **Highlights:**
  - Automated metrological compliance validation against international OIML R-76 standards
  - Cryptographic tamper-evidence using Ed25519 signatures
  - Structured DCC (Digital Calibration Certificate) XML and long-term archivable PDF/A-3 generation
  - Multi-platform workbench scripts (Windows batch, PowerShell, Linux shell)

### 🔐 Encryption & Decryption Tool
**Desktop Cryptographic Security Application**

- **Description:** A desktop application engineered with Python and Tkinter providing symmetric encryption and decryption capabilities using the Fernet algorithm.
- **Core Technologies:** Python, Tkinter GUI, Cryptography (Fernet), OS Module
- **Repository:** [Encryption-and-Decryption-Tool](https://github.com/Manshi-Chauhan/Encryption-and-Decryption-Tool)
- **Key Features:**
  - AES-128-CBC encryption with HMAC authentication via Fernet
  - Automated secret key generation (`secret.key`) and safe local persistence
  - Interactive graphical interface with input validation and error dialogs
  - Protection against invalid or corrupted encrypted payloads
