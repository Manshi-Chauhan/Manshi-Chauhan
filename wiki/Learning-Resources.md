# 📚 Learning Labs & Resources

A curated repository of educational frameworks, technical references, and learning paths that shape my engineering knowledge across Python, Cryptography, and Data Systems.

---

## 🐍 Python & Software Architecture

- **Fluent Python** by Luciano Ramalho — Essential guide for idiomatic Python, data models, and closures.
- **Python Crash Course** by Eric Matthes — Practical project-based fundamentals.
- **PEP 8 & PEP 484** — Official specifications for code style and type annotations.
- **Architecture Patterns with Python** by Harry Percival & Bob Gregory — Clean architecture and test-driven development.

---

## 🔐 Cryptography & Information Security

- **Serious Cryptography: A Practical Introduction to Modern Encryption** by Jean-Philippe Aumasson — Foundational guide on symmetric ciphers, hashing, and authenticated encryption.
- **Cryptography Python Library Documentation (pyca/cryptography)** — Authoritative reference for Fernet, primitives, and hazard guidelines.
- **OIML R-76 Technical Standards** — Metrological requirements and electronic security specifications.
- **OWASP Secure Coding Practices** — Defensive checklist for software development and vulnerability mitigation.

---

## 📊 Data Scraping & Analytical Science

- **Web Scraping with Python** by Ryan Mitchell — Deep dive into BeautifulSoup, handling dynamic pages, and robots.txt compliance.
- **Python for Data Analysis** by Wes McKinney — Authoritative reference for Pandas, NumPy, and data wrangling.
- **Requests Documentation** — Best practices for resilient HTTP client configuration and connection pooling.
